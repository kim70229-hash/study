# # Streamlit 학습 프로젝트

## 1. 프로젝트 소개
Python과 Streamlit을 활용하여 웹 애플리케이션을 개발하는 학습 프로젝트입니다.

## 2. 프로젝트 구성

| 파일명 | 설명 |
|---|---|
| `app.py` | 메인 애플리케이션 및 페이지 이동 설정 |
| `page_1.py` | 첫 번째 페이지 |
| `page_2.py` | 두 번째 페이지 |
| `page_3.py` | 세 번째 페이지 |
| `requirements.txt` | 프로젝트 실행에 필요한 라이브러리 목록 |

## 3. 사용 기술
- Python
- Streamlit
- Git / GitHub
